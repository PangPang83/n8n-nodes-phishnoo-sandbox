# Phishnoo Sandbox node for n8n

Read synthetic scores or submit an example threat report. Use an operator-issued sandbox key in the Phishnoo Sandbox API credential.

This is an unsigned development package. Install it on a development n8n instance for runtime review. Verified community publication requires the maintainer's npm namespace, provenance, and an n8n submission.
